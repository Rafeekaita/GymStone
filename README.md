# Gym Stone Club

Static site for Gym Stone Club, Malki / Chamstone, Damascus. English default with an Arabic (RTL) toggle.

## Files
- `index.html` — the site
- `styles.css` — all styling and tokens
- `photo-floor.webp` — hero / weights-floor photograph
- `membership-sheet.html` — printable A4 rate sheet (needs `doc-page.js`)
- `instagram-card.html` — 1080x1350 feed post

## Deploy
Push the contents of this folder to the repository root and enable GitHub Pages on `main` / root. No build step.
